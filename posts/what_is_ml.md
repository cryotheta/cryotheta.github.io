# What is Machine Learning?

**Date:** 2026-01-19  
**Tags:** AI, Intro, Education

Machine Learning (ML) is often mystified as "magic" or "robot intelligence", but at its core, it is simply **statistics on steroids**.

## It's All About Patterns

Traditional programming involves giving a computer a set of rules:
> "If input is A, do B."

Machine Learning involves giving a computer a set of outcomes:
> "Here is A, and the result was B. Figure out the rule."

### The "Black Box"
We often call complex models "Black Boxes" because while we know the math (matrix multiplications, non-linear activations), the *emergent behavior* is hard to trace back to a single line of code.

## Why Now?
1. **Data**: We have more digital data than ever before.
2. **Compute**: GPUs (Graphic Processing Units) turned out to be really good at the math needed for ML.
3. **Algorithms**: Improvements in things like Transformers (the T in GPT) have revolutionized the field.
